هل أنت متأكد من حذف هذا العنصر؟ سيتم حذفه من قاعدة البيانات ومن جميع أجهزة المستخدمين فوراً.

إعداد قواعد أمان Firebase Firestore

للسماح للوحة التحكم وللتطبيق بنشر وعرض التطبيقات دون قيود أمنية

إذا ظهرت لك رسالة خطأ (Permission Denied أو Missing or insufficient permissions):

  1. ادخل إلى Firebase Console > Firestore Database > Rules.
  2. استبدل القواعد الحالية بالقواعد المفتوحة التالية:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
  1. اضغط على زر Publish (نشر) في Firebase Console.
  2. ارجع إلى هذه الصفحة واضغط "حفظ ونشر" وسينجح النشر فوراً دون أي خطأ!
